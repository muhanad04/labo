# Original project brief

This file preserves the discovery brief's intent. Current product truth is in [../PRODUCT.md](../PRODUCT.md); implemented scope is in [NOW.md](NOW.md). Do not treat the initial proposal as a second current specification.

## Purpose

Give university students an affordable place to build, predict and measure electrical circuits in a browser. Prioritize understandable, trustworthy results over breadth or equipment realism.

The DC-first slice has expanded to ideal DC/single-frequency RMS AC, RLC/phased sources, basic three-phase networks, routed/group editing, sweeps, snapshots and named local projects. It is not a complete guided course, transient engine or electrical-machines lab; exact limits are in MODELS.md.

## Original success criterion

A student can independently build a supported circuit, understand wiring errors, obtain validated readings, compare them with an analytical prediction, and reopen the experiment. Core usage requires no paid runtime service.

## Still open

Confirm the actual first course and student device/language needs. For rotating machines/transformers, scope and validate one actual experiment; existing linear three-phase circuits are not a substitute for a machine model.

## Not a goal

Vendor-compatible files or equipment replicas, copied courseware, access/licensing workarounds, or implied affiliation. See [VISION.md](VISION.md) for the longer-term independent direction.
